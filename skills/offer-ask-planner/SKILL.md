# Offer Ask Planner

## Workflow

1. Extract current offer terms, deadlines, constraints, and the user's priorities.
2. Separate negotiable items from likely fixed terms.
3. Build a negotiation package with primary ask, fallback ask, and walk-away point if the user supplied one.
4. Draft concise scripts for recruiter calls and written follow-up.
5. Flag legal, immigration, tax, or benefits issues that require qualified advice.

## Ground Rules

- Do not invent market data or competing offers.
- Do not pressure the user toward risk they did not accept.
- Keep scripts polite, specific, and easy for the recruiter to route internally.
- Prefer package asks over scattered concessions.
- Preserve relationship value while making the business case clear.

## Output

Return:

- Negotiation objective.
- Ask package with rationale.
- Call script.
- Written follow-up draft.
- Risks, unknowns, and recommended next step.
